# CraftV - Create Your CV

CV builder that works in your browser and made with React and Vite. Fill in your details,see preview dynamically as you write,choose a template and download your CV as PDF.

## Features

- Add personal information, education, experience, skills, projects, certificates, exams, languages and other details.
- Switch the CV preview labels to get the CV as English or Turkish.
- Choose a template and download your CV as PDF.
- Data is handled in the browser and is not sent to a remote database.

## Built With

- React
- Vite
